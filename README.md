# BMI Calculator in C

## Description

This software is specifically developed for Latin America, using the International System of Units (SI): distances in meters (m) and mass in kilograms (kg). 

This project was developed as part of a Computer Science assignment for the Electronic Engineering program.

The application calculates the Body Mass Index (BMI) using the user's weight and height. BMI is a widely used indicator that helps estimate whether a person's weight is within a healthy range.

## Formula

BMI = Weight (kg) / Height² (m)

## Features

- Input of weight in kilograms.
- Input of height in meters.
- Automatic BMI calculation.
- Display of the calculated result.

## Technologies

- C Programming Language
